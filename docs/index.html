🔍 Availability scan

Generate usernames and check them against Roblox's validation service.

✨ Aesthetic mode

Favor more pronounceable results using consonant/vowel patterns and a word-like scoring heuristic.

⌨️ Manual lookup

Check a name you already have in mind and claim an available result.

🔐 Secure credential saving

Single-name claims generate a strong password and store it with the username in Windows Credential Manager.

🌐 Autofill companion

Optional Chrome/Edge extension can fill birthday, username, and the saved password on Roblox Create Account.

🧯 Tab limiter

Choose how many browser tabs to open. The default cap is 10, with 0 available to skip.

Secure claim workflow

v2.4: Single-name claim mode generates a strong password, saves the username/password pair in Windows Credential Manager, then opens Roblox Create Account. The optional Chrome/Edge companion can fill the saved birthday, username, and password automatically. The final Create Account click is always left to you.

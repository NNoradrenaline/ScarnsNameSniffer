A scanner engine, not just a random-name loop.

v2.6 spends requests more intelligently and gives useful information back while it works.

✓ Two-stage verification

Potentially available names get a second Roblox username lookup before receiving the VERIFIED label.

⚡ Adaptive workers

Concurrency increases when responses are healthy and backs off automatically when rate limiting or latency rises.

💾 SQLite cache

Recent checks are cached locally, reducing duplicate requests and keeping scan/history data between launches.

⏯ Resume scans

Ctrl+C safely checkpoints long scans. Pick Resume later and continue with the same target and configuration.

★ Watchlist

Track specific names with priority levels and re-check them for status changes when you want.

📊 Live telemetry

See throughput, ETA, API latency, cache hits, worker count, verified results, and rate-limit behavior live.

🧠 Ranked generation

Generate multiple candidates and prioritize cleaner names using a 0–100 quality score.

4 + 5 + 6 together

Scan one length or combine several lengths in the same run.

🩺 Diagnostics

Check the database, credential API, clipboard helper, browser companion files, and Roblox API connectivity.

Download from Releases

Normal users do not need Python or PyInstaller. Grab the prebuilt Windows release and optional Chrome/Edge companion.

Open GitHub Releases.
Choose the newest v2.6 release and download ScarnsNameSniffer.exe.
Optional browser companion.
Download ScarnsNameSniffer-Autofill-v2.6.zip, extract it, then load the folder from Chrome or Edge's extensions page.
Start scanning.
Use smart scan for general hunting, aesthetic scan for cleaner candidates, Watchlist for names you care about, or Diagnostics when something looks wrong.

Local-first data.

Passwords do not go into the v2.6 database. Username checks, cache entries, checkpoints, and watchlist metadata use local SQLite. Generated signup credentials continue to use Windows Credential Manager. The tool does not require an existing Roblox password, cookie, or authentication token.
